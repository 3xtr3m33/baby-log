# Дневник ухода

PWA для учёта кормлений, подгузников и сна. Общий журнал на семью: записи видят все, кто вошёл
по одному коду приглашения. Работает офлайн, ставится на телефон иконкой.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/ (иконки генерируются автоматически)
npm run preview  # посмотреть собранную версию
```

Перед первым запуском впишите свои ключи в `.env.local`:

```
VITE_SUPABASE_URL=https://ваш-проект.supabase.co
VITE_SUPABASE_ANON_KEY=anon-public-ключ
```

Ключ `service_role` в приложение не попадает и попадать не должен.

## Как устроено

- `src/lib/db.js` — локальная база (IndexedDB). Экран читает только отсюда, поэтому приложение
  открывается мгновенно и работает без сети.
- `src/lib/sync.js` — очередь отправки, подтягивание изменений, realtime-подписка.
  Действие пользователя пишется локально сразу, сеть догоняет потом.
- Удаление — это `deleted: true`, а не удаление строки: иначе оно не доедет на второй телефон.
- Конфликты решаются по `id`, выигрывает запись с бо́льшим `updated_at` (его ставит сервер).
  Исключение — записи, ещё стоящие в очереди отправки: их сервер не затирает.

## Схема базы

SQL для Supabase — в инструкции по развёртыванию (таблицы `families`, `members`, `events`,
функции `my_family`, `create_family`, `join_family`, RLS и `supabase_realtime`).
